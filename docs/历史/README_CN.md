# Excel 表格关键字搜索工具 v0.3.0 — 使用说明书

## 一、软件简介

本工具是一个 Windows 独立脱机程序，用于导入 Microsoft Excel 表格文件（.xlsx、.xls 与加密格式 .xse），通过关键字快速搜索表格内容，并支持在搜索结果中进行二次筛选、批量屏蔽、导出与颜色标记等操作。

v0.2.0 新增表格加密搜索能力：表格可预先由专用加密工具加密为 .xse 文件分发，本程序自动解密后即可正常搜索，全程无需任何操作。程序无需连接互联网、无需安装 Excel 即可使用；同时支持通过内网共享目录统一分发数据（共享模式，见 2.2 节）。

## 二、基础操作

### 2.1 准备数据

- 程序自动扫描与 `excel_search.exe` 同目录下 `data` 文件夹内的所有表格与文本文件：
  - `.xlsx` / `.xls`（Excel 表格）
  - `.xse`（加密表格）
  - `.csv`（逗号分隔文本，第一行为表头）
  - `.docx`（Word 文档，按段落搜索）
  - `.png` / `.jpg` / `.jpeg` / `.bmp`（图片，自动文字识别 OCR 后搜索，需 Windows 10 及以上系统）
- 支持中文文件名
- 点击【打开文件夹】可直接在资源管理器中打开 `data` 文件夹
- 新增或删除文件后，点击【重新加载】即可生效，无需重启

### 2.2 共享模式（网络共享数据）

若多个终端需要共用同一份表格数据（由一台分享机通过内网共享目录分发），可使用共享模式，避免每台终端各自存放一份文件：

- 点击主界面【模式切换】按钮，选择"共享模式"即可生效（默认共享路径为 `\\server\share\excel_search`）
- 共享路径由管理员在管理后台的"共享路径设置"中配置（普通管理密码即可进入）
- 共享模式下程序直接读取分享机共享目录中的 `.xlsx` / `.xls` / `.xse` 文件，搜索、二次筛选、智能列、屏蔽、标记、导出等功能与本地模式完全一致
- 共享模式下**不执行明文自动删除**（数据由分享机管理员统一维护，客户端只读）
- 若共享目录暂时不可达（如分享机关机、网络断开），程序会自动使用本机缓存数据，并在状态栏提示"共享目录不可达"；恢复后可点击【重新加载】重试
- 切换回本地模式：再次点击【模式切换】，选择"离线模式"即可

### 2.3 统计报表

- 点击主界面【统计报表】按钮，可查看按文件、工作表汇总的**核定工日合计**、有效行数、总行数
- 底部显示全部文件的总计
- 点击【导出 CSV】可将统计结果导出为 `核定工日统计.csv`（保存到程序同目录的 `导出` 文件夹）并用文件管理器打开

### 2.4 缓存机制

- 首次加载后，程序会保存数据缓存（缓存文件已加密存储，本机落盘不泄密）
- 再次启动时，若 `data` 文件夹内文件数量与文件名均未改变，且距上次加载不超过 10 天，则直接使用缓存快速启动
- 文件变化或超过 10 天将自动重新读取全部表格

### 2.5 一级搜索

1. 在一级搜索框输入关键词（支持中文、英文、数字）
2. 按回车键或点击【搜索】按钮
3. 搜索结果展示在列表中，每条显示所属文件、工作表、行号、匹配内容等

搜索规则：不区分英文大小写，采用"包含"匹配，即单元格内容包含关键词即可命中。同一行中多处命中同一关键词时仅显示一条结果。

**智能搜索增强**：
- **拼音首字母搜索**：直接输入拼音首字母即可命中中文内容。例如输入 `hdgr` 可搜到"核定工日"、输入 `zs` 可搜到"张三"
- **模糊搜索**：若精确搜索无结果，程序自动尝试模糊匹配（容忍个别错字、顺序差异），状态栏会显示"模糊搜索"提示
- **正则搜索**：输入以 `re:` 开头的内容即按正则表达式匹配（适合精确模式）。例如：
  - `re:\d{6}` —— 搜 6 位连续数字
  - `re:MMN\d{3}` —— 搜工时代码（MMN + 3 位数字）
  - `re:[A-Z]{2}\d{8}-\d{2}` —— 搜工单号格式
  - `re:^MMN` —— 搜以 MMN 开头的内容

### 2.6 查看行详情

- 双击任意结果行，弹出"行详情"窗口
- 窗口显示该行所有列的数据，其中匹配单元格、核定工日、工时代码单独列出
- 详情内容可选中复制（Ctrl+C）
- **鼠标悬停结果行**可快速预览该行全部内容（无需双击）

### 2.7 二级搜索（结果中筛选）

1. 完成一级搜索后，在二级搜索框输入关键词
2. 按回车键或点击【二次筛选】按钮，在当前结果中进一步筛选
3. 可多次进行二级搜索，逐级缩小范围
4. 点击【清除筛选】恢复一级搜索的完整结果

相关提示：

| 情况 | 提示内容 |
|------|---------|
| 未进行一级搜索就使用二级搜索 | "未进行一级搜索，请先进行一级搜索" |
| 一级搜索框被清空后使用二级搜索 | 同上，并清空已有结果展示 |
| 一级搜索无结果时使用二级搜索 | "一级搜索内容为空，无法使用二级搜索，请确认搜索内容" |
| 二级搜索无匹配结果 | "未搜索到含有'关键词'的内容，请确认搜索条件并重试" |
| 存在二级筛选时使用一级搜索 | "当前页面存在二级搜索结果，请先清除筛选或将二级搜索框清空" |

### 2.8 输入辅助

- 两个搜索框在未输入内容时显示灰色提示文字
- 按键盘 Tab 键可在一级搜索框与二级搜索框之间切换焦点

## 三、加密文件（.xse）支持

### 3.1 什么是加密文件

- `.xse` 是由专用加密工具将 `.xlsx` / `.xls` 表格加密后生成的加密文件
- 加密前内容已格式统一化，任何第三方软件（Excel、WPS 等）均无法打开
- 即使被非法解密，也无法还原为原始表格文件格式
- 由管理员统一加密后分发，客户端无需安装加密工具

### 3.2 使用方法

- 将收到的 `.xse` 文件直接放入 `data` 文件夹即可
- 程序自动解密并加载，搜索、智能列、屏蔽、标记、导出等全部功能与普通表格完全一致
- 无需输入密码、无需任何额外操作

### 3.3 明文自动删除机制

- 若 `data` 文件夹中同时存在同名的 `.xse` 加密文件与明文表格（如 `员工表.xse` 与 `员工表.xlsx`），程序将自动比对：
  1. 文件修改时间与文件大小
  2. 第二列（B 列）的全部单元格文本
- 两者完全一致时，程序将自动删除明文表格文件（无声提示，防泄密设计）
- 若内容不一致（明文被修改过），明文文件将保留，不会被删除

### 3.4 无效文件检测

- 程序会校验每个 `.xse` 文件是否真实有效
- 无效文件将被跳过、不参与搜索，并在左下角提示条显示原因（持续 10 秒）：
  - **格式无效**：文件并非加密文件（如误改名的其他文件）
  - **附加密码错误**：该文件加密时启用了附加密码，输入的密码不正确
  - **数据损坏**：文件内容被篡改或损坏
- 无效文件不影响其他正常文件的加载与搜索

### 3.5 附加密码文件

- 若某个 `.xse` 文件在加密时启用了附加密码，首次加载该文件时会弹出密码输入框
- 输入正确密码后，本次运行期间不再询问
- 密码由文件分发方告知

## 四、智能列展示

### 4.1 核定工日列

- 程序自动在每张表的首行（表头）中查找包含"核定工日"文字的列
- 多个列包含该文字时，自动选择匹配度最高的一列
- 该列展示选中行对应位置的内容，数值自动保留两位小数（四舍五入）
- 若表头无"核定工日"相关列：该列留空
- 若有该列但该行无数据：显示"无核定工日"

### 4.2 工时代码列

- 匹配规则与"核定工日"相同，自动识别表头中包含"工时代码"的列
- 显示对应内容（通常为 6 位大写字母与数字组合）

### 4.3 任务标题列

- 在使用标记筛选功能时（见第七章），"匹配内容"列将显示该行"任务标题"列的内容
- 识别规则与上述两列相同

## 五、多选操作

- 按住 Ctrl 键点击：逐个多选
- 按住 Shift 键点击：范围选择
- 多选状态下右键菜单的部分功能可批量作用于所有选中条目

## 六、右键菜单功能

在结果列表中点击鼠标右键，弹出菜单包含三项功能。

### 6.1 屏蔽

二级菜单包含：

| 选项 | 说明 | 可用条件 |
|------|------|---------|
| 屏蔽当前条目 / 屏蔽所选条目 (N) | 屏蔽选中的条目，之后搜索不再显示 | 任意选择 |
| 屏蔽当前文件 | 屏蔽该条目所属的整个文件，之后搜索不再显示该文件任何内容 | 仅单选时 |

- 执行前弹出确认窗口，明确提示屏蔽内容
- 屏蔽生效后，左下角临时提示"已屏蔽: N 条"（持续 10 秒）
- 屏蔽状态持久保存，重启后仍有效

### 6.2 导出

将选中条目导出为新的 .xlsx 文件：

- 仅允许导出同一文件内的条目：若选中内容来源为多个文件，提示"所选择的内容来源为多个文件，不允许导出，请选中单文件内的数据进行导出"
- 导出文件包含原表头行与所选条目的完整行数据
- 命名规则：
  - 单条导出：以该条目"匹配内容"列的内容命名（如 `张三.xlsx`），重名自动追加序号
  - 多条导出：命名为 `组合导出1.xlsx`、`组合导出2.xlsx`……自动识别已有最大编号并递增
- 导出文件保存在程序同目录下的 `导出` 文件夹（不存在时自动创建）
- 每次导出完成后自动打开 `导出` 文件夹

### 6.3 标记

二级菜单包含六项：

| 选项 | 效果 |
|------|------|
| 红色 / 紫色 / 蓝色 / 绿色 / 黄色 | 将选中条目的整行文字改为对应颜色 |
| 取消标记 | 恢复默认颜色 |

- 所用颜色均与白色背景保持足够对比度，清晰易读
- 支持多选批量标记
- 标记状态持久保存，重启后仍有效

## 七、标记与颜色筛选

### 7.1 显示全部已标记条目

一级搜索框输入 `已标记颜色` 并回车，列出所有被标记过的条目。

### 7.2 按颜色直接筛选

一级搜索框输入 `已标记红色` / `已标记紫色` / `已标记蓝色` / `已标记绿色` / `已标记黄色`，直接筛出对应颜色的标记条目。

### 7.3 二级颜色筛选

使用 `已标记颜色` 搜索后，在二级搜索框输入颜色名称（红色、紫色、蓝色、绿色、黄色）并筛选，可仅显示该颜色的条目。

### 7.4 任务标题显示

标记筛选状态下，"匹配内容"列自动显示该行"任务标题"列的内容（见 4.3 节）。

## 八、常见问题

**Q: 状态栏显示"未找到表格文件"？**
A: 请将 .xlsx / .xls / .xse 文件放入程序同目录的 `data` 文件夹，点击【重新加载】。

**Q: 搜索不到内容？**
A: 检查关键词拼写。搜索采用"包含"匹配，输入越精确结果越少。注意部分结果可能已被屏蔽。

**Q: data 文件夹里的明文表格文件不见了？**
A: 这是 v0.2.0 的防泄密设计。当同名 .xse 加密文件与明文表格内容完全一致时（修改时间、大小、第二列内容三重比对），程序会自动删除明文文件。若您仍需保留明文，请在放入前修改其内容，或将明文存放在其他文件夹。

**Q: .xse 是什么文件？从哪里获得？**
A: .xse 是由专用加密工具加密生成的表格文件，由数据管理员统一制作分发。客户端无需安装加密工具，直接放入 `data` 文件夹即可使用。

**Q: 左下角提示"已跳过 N 个无效加密文件"？**
A: 对应的 .xse 文件未通过校验（格式无效、附加密码错误或数据损坏），已被跳过。请向数据分发方确认文件是否完整、密码是否正确。

**Q: 打开程序时弹出密码输入框？**
A: 该加密文件启用了附加密码保护，请输入数据分发方提供的密码。输入正确后本次运行不再询问。

**Q: 导出时提示"来源为多个文件"？**
A: 导出仅支持同一文件内的条目，请只选择属于同一表格的条目再导出。

**Q: 表格内容更新了但搜索结果没变？**
A: 点击【重新加载】重新读取文件。若处于共享模式，请确认分享机共享目录可达，再点击【重新加载】。

**Q: 状态栏提示"共享目录不可达"？**
A: 程序处于共享模式，但分享机共享目录当前无法访问（分享机关机、网络断开或路径配置有误）。程序会临时使用本机缓存数据；请恢复网络或联系管理员检查共享路径设置，然后点击【重新加载】。

**Q: 如何切换本地数据与共享数据？**
A: 点击主界面【模式切换】按钮，选择"离线模式"（本机 data 文件夹）或"共享模式"（分享机共享目录）。共享路径由管理员在管理后台"共享路径设置"中配置。

**Q: 支持哪些格式？**
A: 支持 .xlsx（Excel 2007 及以上）、.xls（Excel 97-2003）、加密格式 .xse、.csv 文本、.docx Word 文档，以及 .png/.jpg/.jpeg/.bmp 图片（需 Windows 10 及以上系统，自动 OCR 识别后搜索）。

**Q: 如何查看搜索历史？**
A: 点击一级或二级搜索框旁的【历史▾】按钮，弹出最近使用过的关键词（最多 20 条），点击即可填入搜索框。历史自动保存。

**Q: 如何开启深色模式？**
A: 进入管理后台（一级框为空、二级框输入隐藏入口关键词，再输入管理密码），点击"深色模式"按钮切换。深色模式降低强光刺激，适合长时间使用。

## 九、注意事项

1. 离线模式下程序脱机运行，无需任何网络连接；共享模式需要能访问内网分享机共享目录（无需互联网）
2. 支持 .xlsx、.xls、.xse、.csv、.docx 与图片格式（OCR）
3. 搜索不区分英文大小写，支持拼音首字母、模糊匹配与正则表达式（`re:` 前缀）
4. 表格内容全部加载到内存中，文件过多或过大时可能占用较多内存，建议文件总数控制在 100 个以内
5. 屏蔽、标记等个性化设置自动保存，重启后保留；搜索历史同样自动保存
6. 缓存文件与配置文件均已加密存储
7. 程序需以管理员权限运行（启动时如有 UAC 提示请点击"是"）
8. 共享模式下程序不自动删除明文表格（防泄密清理由分享机管理员统一处理）
