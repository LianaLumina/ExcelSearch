# 控件动效设计说明（V0.3.1.5 原型内）

> 面向：验收者、回迁负责人、后续改动效的人。
> 代码位置：`main.cpp` 顶部「控件动效总纲」一节（`g_noAnim` / `animMs()` / 时长档位 / **曲线库**），
> 以及自绘控件（`FolderBtn` / `WinBtn` / `CardHeader`）、`FadeSlideEffect`、`RowDelegate`、`StateTint`、
> `CollapseCard`、`LoadBar`。
> 回迁注意见 `docs/回迁标注.md` 第 16 / 19 / 20 条。
>
> 版本说明：本文档描述 **V0.3.1.5 第二轮（现代感 / 灵动感增强）** 后的状态；
> 第一轮的"克制基线"仍是硬约束（时长 ≤240ms、只作用子控件、令牌取色、可一键关闭）。

## 0. 一句话

给功能已完备的原型加**一层克制、跟手的控件动效**，让它从"能用"变成"有质感"，**不改变任何业务行为**，
并且**可以一键关掉**。第一轮解决"跟手与状态可读"（hover / 页面切换 / 可折叠卡片 / toast）；
第二轮解决"现代与灵动"：**运动语言令牌化**（曲线分三类 + 时长三档 + 错峰）、
**数值滚动**、**结果表入场错峰**、**父子错峰编排**（容器先到、内容随后）、
**方向感知切页**、**选中态交接**、**加载进度细条**、**失败抖动**。

## 1. 动效简报

| 项 | 取值 |
|---|---|
| 载体 | Qt6 Widgets 桌面程序（1020×700 默认窗口，无边框自绘标题栏） |
| 观众 | 内部使用者（Excel 表格关键字检索的日常使用者），不是展示型观众 |
| 目的 | **状态可读性**：让"能点/在切换/已展开/在过渡"这些状态一眼看得出来，而不是装饰 |
| 品牌约束 | MAA 风格 —— 科技蓝 `#326cf3`、深色面板 `#17171C`/卡片 `#24242B`、浅色 `#F5F6FA`/`#FFFFFF`、圆角、微软雅黑 |
| 颜色来源 | **只能取 `Proto` 令牌**（`accent/hover/pressed/text/sub/closeHover/panelBg/card`），不硬编码 |
| 平台约束 | 顶级无边框窗口开了 `WA_TranslucentBackground`，Win10 下做尺寸/位置动画会闪 → **窗口本体永远静止，动效只作用在子控件上** |
| 帧率/时长 | 90–240ms，三档（kDurMicro/Base/Slow）；只表达层级 / 因果 / 状态，不做装饰性动作 |
| 无障碍 / 可复现 | `UI_PROTO_NO_ANIM=1`（或 `--no-anim`）= 关闭动效并**直接落终态**（等价"减少动态效果"） |
| 验收判据 | 关闭动效时 13 张截图与动效前**逐字节一致**；动效开启（落定后）与关闭动效**逐像素一致**（两组实测均为 0 差异） |

## 2. 动效语法（grammar）

| 维度 | 规则 |
|---|---|
| **曲线库**（一处定义，全项目共用） | `curveEnter()` = EmphasizedDecel `cubic-bezier(.05,.7,.1,1)`：进场（起步快、尾巴长）<br>`curveStandard()` = Standard `cubic-bezier(.2,0,0,1)`：状态/颜色/位移的状态间过渡<br>`curveExit()` = EmphasizedAccel `cubic-bezier(.3,0,.8,.15)`：退场（化开走掉）<br>`curveSpring()` = 二阶阻尼（ζ=0.7 / ω=16，过冲 ≈4.6%、峰值在过程 30% 处）<br>`curveCount()` = OutExpo：只给数字滚动用 |
| **颜色的铁律** | 颜色过渡一律用 `curveStandard`/`curveExit`，**绝不用弹簧** —— 颜色过冲看起来就是"闪一下" |
| 时长档位 | `kDurMicro 90`（按下/抖动起步）/ `kDurBase 160`（页面·分区）/ `kDurSlow 240`（数值·入场）<br>另有：hover 120 / 折叠 180 / toast 150 / 数值滚动 420 / 焦点 140 / 交接 140 |
| **错峰（stagger）** | `kStaggerMs 40`（父子：容器先到 30%，内容随后）；`kRowStaggerMs 20`（结果表行，最多 8 行）<br>错峰一律用**单动画 + 每元素相位公式**实现（`相位 = f(动画值, 序号)`），不用多个定时器、不用墙上时钟 |
| 位移 | 页面 8px（**方向感知**：往右切从下方进、往左切从上方进）；toast 10px；折叠内容体 6px；抖动 ±6px<br>位移在 `FadeSlideEffect` 内部完成（见下） |
| 淡入 / 淡出 | 复用同一个 `FadeSlideEffect`（不透明度 + 位移）；**只在动画期间挂着**，一结束立刻摘掉（长期挂着会改渲染路径、伤性能）<br>**不再用"动画布局边距"**：那会每帧重排整棵子树（页面里挂着结果表），既费又抖 |
| 进入 / 停留 / 退出 | 进入 = 淡入 + 方向位移；停留 = 完全静止（除加载细条这种"不确定进度"提示）；退出 = 位移+淡出（toast / 选中交接） |
| 层级关系 | 顶层切换（tab）幅度最大 → 分区切换略小 → 卡片内容再小 → hover 只有颜色；越靠近内容，动作越小 |
| 状态表达优先 | 勾选态（顶部标签当前页）、选中态（列表项）不参与 hover/按下过渡；按下是**独立**的快速反馈 |
| 数据即动效 | 数字变化一律**滚动**到目标值，且**精确落定**（绝不停在中间值） |
| 重复性 | 一套机制复用：`HoverT`（自绘 hover/按下）、`StateTint`（QSS 控件三态）、`enterAnim()`（淡入+位移+子元素错峰）、`FadeSlideEffect`（唯一的渲染效果）、`shakeAnim()`（失败反馈） |

实测证据（离屏可复现，见第 6 节）：

- 折叠（收起）轨迹 **601px → 515px → 405px → 340px**（t≈40/90/150/260ms），逐段收窄 = 减速；
  关闭动效时同一条命令**直接就是 340px**，且 t=260ms 与终态**逐像素相同**（effect 已摘干净）。
- 方向感切页：设置卡片上缘在 t=20/80/落定 ms 分别 **y=103 → 99 → 97**（8px 被压缩成"快起慢收"）。
- hover 底色 **#F5F6FA → #F0F2F7 → #EAEEF4 → #E9EDF3**（终点 = `Proto.hover` 令牌）；
  `#primaryBtn` **#326CF3 → #2F65E2 → #2D60D9**（终点 = `accent.darker(112)`）。
- 数值滚动中间帧：**38582 / 30**（t=140ms）→ 落定 **43846 / 54**；`--mid 300` 抓到 **43511**。
- 结果表入场中间帧：第 1–5 行已就位、第 6 行正在"洗入"、第 7–8 行尚未出现（t=140ms）。

## 4. 组件契约（谁用哪条路径）

| 对象 | 路径 | 为什么 |
|---|---|---|
| `FolderBtn` / `WinBtn` / `CardHeader`（自绘控件） | `HoverT` 驱动 hover/按下进度（0↔1），`paintEvent` 用 `mixColor()` 在两端**令牌色**之间插值 | 自己画的东西自己控，颜色必然来自令牌 |
| 结果表行 / 各设置列表项（`RowDelegate`） | 委托在**基类之前**自绘 hover 底色；列表 8px 圆角自绘、表格整行 `fillRect`；另有**入场错峰**与**选中交接** | QSS 不支持 transition；装了 QSS 的 `QTableView` 会接管 `::item` 绘制，`QStyleOptionViewItem::backgroundBrush` 会被丢掉（实测设了也一像素不变） |
| `#primaryBtn` / `#themeBtn` / `#tbBtn` / `#navBtn`（QSS 按钮）与输入框 | 运行时挂**控件级样式表**覆盖 background/color/border-color/border-radius（`StateTint`），状态结束立刻清空 | QSS 无 transition；控件级规则优先级更高，能精确覆盖"自己这一条"，且**不动全局 QSS** |
| 页面 / 分区 / 解锁层 / toast / 抖动 | `FadeSlideEffect` + `enterAnim()` / `shakeAnim()` | 位移与淡入都在 effect 内部完成：**不动布局**、方向可正可负、没有边距累加的坑 |
| `CollapseCard`（可折叠卡片） | 只压**高度上限**；同一进度分别驱动容器高度（Enter）、箭头（Spring）、内容体（Standard + 相位） | 不改布局 stretch 因子，展开后窗口缩放行为与动效前一致 |
| `LoadBar`（加载细条） | 叠加在面板顶部、手动定位（不进布局） | 进布局会让整页在加载时上下跳 |
| 统计数字 | `setStat()`：QVariantAnimation 驱动文本 + 结束后**精确落定** | 数字有业务含义，不能只求好看 |

`StateTint` 的四条硬约束（改选择器前必读，代码里也写了）：

1. 选择器"主体"必须与 `qssFor()` 里那条一致：`#primaryBtn`/`#tbBtn`/`#navBtn` 用带 id 的选择器，
   `#themeBtn` 在 `qssFor` 里**没有专属规则**（只吃通用 `QPushButton`）→ 它的选择器就得用 `QPushButton`；
2. 同时挂 `sel:hover{…}` 与 `sel{…}` 两条规则：前者在真机上生效（与全局 `:hover` 同选择器、控件级更靠后），
   后者兜底（离屏/无鼠标环境判定不出 hover 态，自检因此也能截到 hover 终态）；
3. **全程不透明**：透明底按钮的"透明"用 `backDropOf()` 取真实底色（`panelBg` 或 `card`）代替，
   绝不在 QSS 里写半透明背景 —— 实测半透明中间帧会被合成成深灰（`#BBBBBF`），hover 会闪一下；
4. 勾选态（顶部标签"当前页"）**不参与** hover/按下过渡：`:checked` 的强调色是状态表达，不能被冲掉。

## 5. 「关闭动效」开关（硬要求）

| 方式 | 写法 | 说明 |
|---|---|---|
| 环境变量（推荐） | `UI_PROTO_NO_ANIM=1` | 在 `AppWindow` 构造**之前**读取，动画启动前即生效 |
| 命令行 | `ui_proto.exe … --no-anim` | 等价，二者任一即可 |

生效语义（不是"把时长调短"，而是"**直接落终态**"）：

- 所有时长常量经 `animMs()` 返回 0 → 不启动任何动画、不装 `QGraphicsOpacityEffect`；
- 因此**渲染路径与动效前完全一致** → 离屏截图可逐像素比对、自检不随机失败；
- hover 仍工作，只是瞬时（与动效前一致）；折叠仍能展开/收起，只是瞬时到位；
- 数值滚动直接 setText、结果表不做入场错峰、加载细条不出现、不做抖动。

**截图确定性（与开关配套）**：`--shot` 路径会 `setCursorFlashTime(0)` 关掉光标闪烁 ——
焦点输入框的文字光标本来每 500ms 闪一次，会让"逐像素对比"随机差 14px（曾真实发生）。
这一步只作用于截图路径，不影响交互。

`--report` 新增字段 **`anim=on|off`**（既有字段含义不变），用来证明开关确实生效：
`anim=off` = 关，`anim=on` = 开。

## 6.5 第二轮（现代感 / 灵动感）做了什么

| 代号 | 内容 | 关键实现 | 证据 |
|---|---|---|---|
| A1 | 运动令牌 + 曲线库（4 条曲线 + 3 档时长 + 错峰常量） | 全部集中在 main.cpp 顶部，一处改全局变 | 各中间帧颜色/高度轨迹 |
| A2 | 数据概览数值滚动（0/40/80ms 错峰，**只在变大时**） | `setStat()`：OutExpo 420ms，**精确落定**，滚动期预留最小宽度；相等/变小直接落值；`loadData()` 开头**不再刷新**统计数字（加载期间保持旧值） | `--mid 300` = 43511；落定 = 43846；`--reload --mid 30/80/150/300` 数字带与落定帧**0 差异**（全程不动） |
| A3 | hover **圆角微变形**（只改绘制） | `StateTint` 在控件级样式表里插值 `border-radius` | hover 帧 bbox 覆盖按钮全框 |
| A4 | 按下快速反馈（90ms） | `StateTint::toPress()` | — |
| A5 | **方向感知切页** + 无重排位移 | `FadeSlideEffect`（位移在 effect 内，不再动布局边距） | 设置卡片上缘 103→99→97 |

## 7. 刻意不做（以及理由）

| 没做 | 理由 |
|---|---|
| 顶级窗口的尺寸/位置/淡入动画 | 开 `WA_TranslucentBackground` 的无边框窗口在 Win10 下做几何动画会闪（历史已确认，用户选择"质感优先、接受静止"） |
| 卡片 hover "抬升"（阴影/缩放） | Qt 子控件没有阴影/变换能力，用布局位移去模拟会"跳"。改为**标题栏高亮 + 箭头靠向强调色**表达可交互 |
| `#themeToggle`（浅色/深色切换）的 hover 过渡 | 它是 checkable，覆盖 hover 会把 `:checked` 的强调色底冲掉（同优先级时控件级样式表更强），得不偿失 |
| `QMenu`（右键菜单 / 托盘菜单）的 hover 过渡 | 菜单项由 QMenu 自绘，插不进过渡（要换整套 style）；且菜单寿命极短，瞬时高亮反而更跟手 |
| 列表项文字色的过渡 | QSS `::item` 的文字色会覆盖委托里设的 palette，压不住；改为**文字色瞬时切换（与原来一致）+ 底色过渡** |
| 折叠状态持久化 | 会新增配置键 → 配置格式与回迁面变大。保持"重启即全部展开"，配置后端零变化 |
| 循环/装饰性动画（呼吸、流光、粒子） | 与"克制"原则冲突；界面动效只服务于状态可读性（唯一例外：加载细条——它是**功能性**因果提示，且只在后台解析期间出现） |
| 卡片阴影"抬升"（`QGraphicsDropShadowEffect`） | 半透明顶级窗口下阴影效果可能掉帧/边缘发灰，未做实测 → 不进本轮；真要做得先量帧时间 |
| Material ripple（水波纹） | QSS 按钮做不了（覆盖层会盖住并染色文字）；自绘按钮可做但**在一个桌面工具里收益很低**，属于装饰性动作 |
| 顶部窗口入场/几何动画 | 明确不做（同第一轮，见上表首行） |
| 菜单/下拉弹出层的淡入 | `QMenu` 是顶级弹出窗口，透明度动画属"顶层窗口动效"，需先实测不闪；本轮先留空 |
| 动效时长做成配置项 | 原型阶段不值得为一个配置键扩大回迁面；建议回迁后放进「通用设置 → 外观」 |

## 8. 动效与回迁

- 动效代码全部在 `main.cpp` 内，**没有新增文件、没有新增依赖/Qt 模块、没有改 CMakeLists**（`tools/selfcheck.ps1` 只是自检脚本，不参与构建）。
- 回迁时：`docs/回迁标注.md` 第 19 条逐条对照；`grep -n "★回迁注意" main.cpp` 里的动效条目也要过一遍。
- 重点：`animMs()`/时长档位、`backDropOf()` 的容器判定、`StateTint` 的选择器与全局 QSS 的对应关系 ——
  这三处最容易在回迁/改版时被改坏（改坏了表现为"动效看不见"或"hover 闪一下"）。

## 9. 已知取舍 / 遗留

1. **无头环境截不到 QSS 的真实 hover 态**：`--hover` 对 QSS 控件是靠 `StateTint` 的控件级规则兜底截到的，
   真机鼠标 hover 的表现仍需人工过一眼（验收清单第 3 节的手验项）。
2. **折叠状态不持久化**（见第 7 节），重启后两张卡片都展开。
3. **动效时长是编译期常量**，没有做成配置项 —— 原型阶段不值得为它多一个配置键；
   若要给用户调，建议回迁后放进「通用设置 → 外观」，与主题/强调色同区。
4. **hover 过渡靠"每帧改控件级样式表"**（每次约 7 帧），单控件开销很小；
   若将来出现"大量按钮同时 hover"的场景，应改为自绘或 `QProxyStyle`。
