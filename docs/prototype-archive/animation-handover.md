## 2. 关闭动效的开关（验收必须用它）

| 方式 | 写法 |
|---|---|
| 环境变量（推荐） | `UI_PROTO_NO_ANIM=1` |
| 命令行 | `ui_proto.exe … --no-anim` |

- 在窗口构造**之前**生效；语义是"**直接落终态**"（时长归零、不装 effect、不起动画），**不是**把时长调短。
- 截图/自检**必须带上**，否则会拍到中间态；关闭时渲染路径与动效前一致。
- `--report` **新增字段 `anim=on|off`**（既有字段含义与顺序未变），用来证明开关真的生效。
- 与开关配套的两个确定性措施（不加会误判）：
  1. `--shot` 路径会 `setCursorFlashTime(0)` 关掉焦点输入框的光标闪烁 —— 光标每 500ms 闪一次，
     会让逐像素对比**随机差 14px**；
  2. 截图默认等待 `kSettleMs = 760ms`（覆盖最长动效链：数值滚动 420 + 错峰 80 + 切页 160 + 余量）。
     **以后加更长的动效要同步调大**，否则会拍到中间帧（返工过一次：43846 被拍成 43844）。

## 6. 截图 / 自检钩子（新增，验收会用到）

| 参数 | 作用 |
|---|---|
| `UI_PROTO_NO_ANIM=1` / `--no-anim` | 关闭全部动效，直接落终态 |
| `--collapse 0,1` | 截图前折叠搜索页第 0/1 张卡片（0=数据概览 1=搜索结果） |
| `--hover <名>` | 强制某控件到某个动效状态：`primaryBtn` / `themeBtn` / `tbBtn` / `navBtn[N]`（自动挑**可见**的）、`row[N]`（结果表行）、`sec[N]`（设置列表项）、`folder` / `close`（自绘按钮）、`card`（卡片标题栏）、`loadbar`（加载细条呈现帧）、`shakewrong`（密码错误抖动，走真实解锁路径喂错密码） |
| `--mid <ms>` | 只等指定毫秒再截 → **抓动画中间帧**（用来证明"确实在动"） |
| `--reload` | 先落定、再走真实路径触发一次「重新加载」（验证加载反馈与统计数字行为） |

## 7. 遗留与决策（主会话知悉，必要时再定）

**已按用户反馈改完的两处**

1. 加载/重新加载期间统计数字**保持不变**（不再闪 0）：`loadData()` 开头不再刷新统计；数字只在**变大**时滚动（OutExpo 420ms，**精确落定**），相等或变小直接落值。
2. 任何一次加载（含缓存命中的瞬时加载）都扫一次顶部细条，**最短显示 260ms**（避免"闪一下就没"），且只表达"在干活"、不假装知道进度。

**刻意不做（理由见 `docs/动效设计.md` 第 7 节）**

- `QMenu`（右键菜单 / 托盘菜单）的 hover 过渡：QMenu 自绘路径插不进过渡（要换整套 style）。
- 卡片阴影"抬升"（`QGraphicsDropShadowEffect`）：半透明顶级窗口下可能掉帧/边缘发灰，**未实测**，故不进本轮。
- Material ripple：QSS 按钮做不了（覆盖层会染色文字）；桌面工具里收益很低，属装饰性动作。
- 弹出层淡入（`QMenu` 等）：属"顶级窗口动效"，需先实测不闪，本轮留空。
- 动效时长做成配置项：原型阶段不值得为一个配置键扩大回迁面（建议回迁后放「通用设置 → 外观」）。
- 折叠状态持久化：不新增配置键，保持"重启即展开"。
- 循环/装饰性动画：唯一例外是加载细条（它是功能性因果提示，且只在加载期间出现）。

**无头环境的两个盲区（必须真机手验）**

1. QSS 的**真实鼠标 hover 态**截不到（离屏没有鼠标，`--hover` 是靠控件级规则兜底截到的）；
2. hover 跟手度、切页不闪不抖、折叠手感 —— 只能手验。
